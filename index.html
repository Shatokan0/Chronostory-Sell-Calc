Developer Spec Notes

This estimates the long-run vendor sell average by Monte Carlo simulation, using Boutei's roll rules directly.
The expected vendor sell modifier is derived from Boutei's rarity-color multiplier table.
This is a simulation based on Boutei's provided formulas.
For statdelta, this version follows pseudocode: RandomIntegerRange(-1,1) × RoundToNearestWholeNumber(MOD × RandomIntegerRange(0,1000000) / 1000000).
That means the magnitude roll uses an inclusive 0 to 1,000,000 integer range, then divides by 1,000,000, so exact 0.000000 and 1.000000 are both possible before rounding.
Boutei's text contains one internal RNG conflict: one example says 1 to 1,000,000 divided by 1,000,000, while the formal pseudocode says 0 to 1,000,000 divided by 1,000,000. This file uses the formal pseudocode as the source of truth.
